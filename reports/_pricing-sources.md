# SaaS list prices and adoption figures: sources

Read date for every row: **2026-09-28**.

## How this was collected (read this first)

- **No vendor or third-party page was opened directly.** In this environment,
  `WebFetch` was blocked by the network egress proxy for every domain tried
  (trello.com, asana.com, monday.com, atlassian.com, notion.com, capterra.com,
  g2.com, tech.co). Every figure below therefore comes from **WebSearch result
  summaries** (the search engine's extract of the listed page), not from a
  first-hand page read.
- **Evidence levels** (column "Notes"):
  - **V-search**: the search was restricted to the vendor's own domain, and the
    summary gave the figure from the vendor URL listed. This is the strongest
    evidence here, but it is still a search extract.
  - **3P**: the figure comes from third-party pricing roundups (URL listed).
    When several agreed, this says so.
  - **not verified**: sources conflicted or no price was found. A range is
    given only as context.
- Prices exclude VAT/sales tax, use the vendor's published currency, and are
  per user (seat/agent/member/employee) per month, **billed annually**, unless
  stated otherwise.
- Before quoting a price externally, re-open the vendor URL in a browser and
  confirm it. Prices change often: Atlassian raised cloud list prices on
  2025-10-15, and Slack changed its pricing in June 2025.
